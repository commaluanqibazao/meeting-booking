# 🏢 会议室预定系统

> 9楼办公室 · 金沙滩（10人） · 银沙滩（8人）

一个基于自然语言输入的会议室预定系统。输入一句话就能预定会议室，支持智能解析日期、时间、人数等信息。

## 🚀 快速开始

### 前置条件

- Node.js 18+
- MySQL 8.0+

### 1. 数据库配置

```bash
mysql -u root -p < schema.sql
```

### 2. 安装依赖 & 启动

```bash
npm install
# 修改 server.js 中的数据库连接信息后
npm start
```

### 3. 访问

打开浏览器访问 `http://localhost:3000`

## 🧠 自然语言输入示例

| 输入 | 效果 |
|------|------|
| `明天下午3点到5点金沙滩，5个人，我叫小张` | ✅ 预定明天金沙滩 15:00-17:00 |
| `今天晚上8点用银沙滩，4位，产品评审` | ✅ 今晚银沙滩 20:00-21:00 |
| `后天上午10点到11点半银沙滩，3人` | ✅ 后天银沙滩 10:00-11:30 |
| `下周一14:00-16:00金沙滩，6人` | ✅ 下周一金沙滩 14:00-16:00 |

支持：今天/明天/后天/周X/下周一/X月X号、上午/下午/晚上、X点到Y点/X:00-Y:00

## 🏗️ 技术栈

- **后端:** Node.js + Express
- **数据库:** MySQL
- **前端:** 原生 HTML/CSS/JS（无框架依赖）
- **NLP:** 自研中文自然语言解析器

## 📋 预定规则

- ⏰ 每次最多 **4 小时**
- 📅 最多提前 **7 天** 预定
- 🕐 **24 小时** 可用
- 👥 金沙滩 **≤10人**，银沙滩 **≤8人**
- 🚫 时间冲突自动检测，不可重复预定

## 📡 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/rooms` | 获取会议室列表 |
| POST | `/api/parse` | 解析自然语言输入 |
| GET | `/api/check-availability` | 检查时间段可用性 |
| POST | `/api/bookings` | 创建预定 |
| GET | `/api/bookings` | 获取预定列表 |
| DELETE | `/api/bookings/:id` | 取消预定 |
